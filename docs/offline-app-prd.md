# PoemBud 单机版 PRD

## 1. 产品定位

PoemBud 是一款面向儿童启蒙阶段的单机古诗学习 App。产品核心目标是让孩子在无账号、无联网依赖、无 AI 能力的前提下，完成“发现诗词、学诗、听读、跟读自评、背诵闯关、积累成长”的学习闭环。

本版本强调：

- 单机可用：安装后主要功能不依赖网络。
- 内容真实：诗词正文来自本地内置诗库，不通过运行时网络接口获取。
- 轻游戏化：用星星、关卡、勋章和连续学习降低学习门槛。
- 家长友好：后续提供本地学习报告和家长查看入口，但不做远程同步。

## 2. 明确不做

| 不做项 | 说明 |
| --- | --- |
| 不做 AI 生成 | 不接入 AI 绘图、AI 讲解、AI 文案生成。 |
| 不做 AI 语音评分 | 跟读页不使用“AI 正在听/AI 评测”等表达，不调用云端语音评测。 |
| 不做运行时数据接口 | 诗词、分类、题库都内置在 App 中，不运行时请求诗词接口。 |
| 不做账号体系 | MVP 只保留本地学习档案，不做手机号/微信/云端账号。 |
| 不做云同步 | 学习记录只保存在设备本地。 |

## 3. 用户与场景

### 3.1 目标用户

- 儿童：幼小衔接到小学中低年级，主要完成听、读、背和简单理解。
- 家长：希望孩子每天用短时间积累古诗，不希望 App 依赖网络或复杂账号。

### 3.2 核心场景

1. 孩子打开 App，在首页看到今日推荐和热门古诗。
2. 点击诗词进入学诗页，查看诗文、拼音、逐句讲解。
3. 播放本地范读音频或纯展示诗句。
4. 进入跟读练习，App 录音并提供本地规则化反馈。
5. 完成背诵闯关，获得星星和勋章进度。
6. 在成长报告和我的页查看本地学习成果。

## 4. 信息架构

底部 Tab 建议保持 4 个：

| Tab | 功能定位 |
| --- | --- |
| 首页 | 今日推荐、热门古诗、学习进度、快捷入口。 |
| 诗库 | 搜索、分类、收藏、最近学习。 |
| 学习 | 当前诗词学习页，作为继续学习入口。 |
| 我的 | 本地档案、统计、勋章、家长中心、设置。 |

成长报告作为二级页面，入口放在首页学习进度卡和我的页“学习报告”。这样能保留目标图里的报告能力，又不牺牲“诗库”一级入口。

## 5. 功能需求

### 5.1 首页

| 模块 | 需求 |
| --- | --- |
| 顶部档案 | 展示本地昵称、今日学习状态、勋章入口。 |
| 轮播推荐 | 从本地诗库中读取推荐诗，点击进入学诗页。 |
| 今日推荐 | 展示一首本地推荐诗，包含封面、标题、作者、节选和“学习/听赏”按钮。 |
| 热门古诗 | 展示 4-8 首本地热门诗，支持进入学习页。 |
| 学习进度 | 展示今日分钟、累计天数、7/14/30 天里程碑。 |
| 快捷入口 | 跟读练习、阅读练习/学诗入口。 |

### 5.2 诗库

| 模块 | 需求 |
| --- | --- |
| 本地搜索 | 按标题、作者、朝代、诗句搜索 `offline_poem_library.json`。 |
| 我的收藏 | 展示本地收藏诗，支持进入诗文和取消收藏。 |
| 诗单分类 | 按唐诗、咏月诗、春天的诗、山水田园等本地分类筛选。 |
| 最近学习 | 展示最近打开/学习过的诗，支持继续学习。 |
| 全部列表 | 支持查看全部本地诗词，按难度或年级排序。 |

### 5.3 学诗页

| 模块 | 需求 |
| --- | --- |
| 诗文展示 | 展示标题、作者、朝代、正文、拼音。 |
| 拼音开关 | 支持显示/隐藏拼音。 |
| 收藏 | 本地收藏/取消收藏。 |
| 逐句讲解 | MVP 可使用本地简短释义；没有释义时展示“逐句读一读”。 |
| 赏析 | 使用本地文案，不通过 AI 生成。 |
| 背一背 | 进入本地题库闯关。 |
| 跟读练习 | 进入录音练习。 |

### 5.4 跟读练习

本版本不做 AI 评分，改成“录音练习 + 本地鼓励反馈”。

| 模块 | 需求 |
| --- | --- |
| 句子选择 | 默认从当前诗第一句开始，可切换下一句。 |
| 本地录音 | 调用麦克风权限，保存到本地文件。 |
| 录音回放 | 支持播放最近一次录音。 |
| 规则反馈 | 根据是否完成录音、录音时长、练习次数给星星，不宣称准确率评分。 |
| 跟读记录 | 保存诗 ID、句子、录音路径、练习时间、奖励星星。 |

文案替换建议：

- “AI 正在听你朗读”改为“正在录音，请大声朗读”。
- “发音评分 92 分”改为“完成一次跟读”或“朗读完成度”。
- “字词发音准确度”改为“本句练习记录”或“跟读小提示”。

### 5.5 背诵闯关

| 模块 | 需求 |
| --- | --- |
| 题库 | 本地内置题目，题型包括补字、补句、诗句排序。 |
| 关卡 | 每首诗至少 2-3 个关卡，按难度逐步解锁。 |
| 判题 | 完全本地判题。 |
| 奖励 | 正确后给星星、更新掌握度和勋章进度。 |
| 失败反馈 | 错误后允许重试，给出非 AI 的固定提示。 |

### 5.6 成长报告

| 已掌握古诗 | 根据闯关完成度计算。 |
| 成长曲线 | 使用本地每日/每周记录生成。 |
| 勋章 | 本地规则解锁。 |
| 分享 | MVP 可不做，后续可导出本地图片。 |

### 5.7 我的

| 模块 | 需求 |
| --- | --- |
| 本地档案 | 创建/编辑昵称、头像、年级偏好。 |
| 学习统计 | 已学诗、累计星星、累计天数。 |
| 我的勋章 | 已获得勋章和未获得勋章。 |

## 6. 数据需求

### 6.1 离线诗库

已新增本地数据文件：

`entry/src/main/resources/rawfile/offline_poem_library.json`

当前包含：

- 39 首诗词
- 27 个分类
- 标题、作者、朝代、正文、拼音、年级建议、难度、标签、搜索字段
- 数据源和授权说明

运行时使用方式：

1. App 启动或诗库页面加载时读取 rawfile JSON。
2. 转成内存中的 `PoemItem[]`。
3. 搜索、分类、推荐、学习页都从这个本地数组读取。
4. 不在运行时访问 GitHub、今日诗词或其他诗词接口。

### 6.2 本地学习记录

interface DailyStudyRecord {

## 7. 成功标准

MVP 完成标准：

- 断网打开 App，首页、诗库、学习、我的都能正常使用。
- 诗库能展示 `offline_poem_library.json` 中的真实诗词。
- 能按关键词搜索诗词。
- 能按分类进入诗词列表。
- 学诗页能展示真实诗文和拼音。
- 跟读练习能录音、保存记录、回放，不出现 AI 评分文案。
- 闯关题目来自本地题库，答对后更新本地成长数据。
- 成长报告数据来自本地学习记录，不使用静态假数据。

## 8. 风险与约束

| 风险 | 处理方式 |
| --- | --- |
| 部分诗词版本差异 | 数据文件保留 source 字段，后续人工校对目标教材版本。 |
| 拼音多音字错误 | 当前拼音为开发期工具生成，进入正式版本前需人工校对常见多音字。 |
| 图片/音频资源不足 | 先使用通用封面和无音频状态，后续逐首补本地资源。 |
| 数据源授权 | 不复制 AGPL 项目代码；使用 MIT 数据源时保留授权说明。 |
